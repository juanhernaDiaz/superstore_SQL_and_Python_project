# superstore_SQL_and_Python_project
SQL + Python analysis of the Superstore retail dataset: profit and sales by sub-category, region, and state, plus how discounts affect profit. Built with SQLite, pandas, and matplotlib.

Superstore dataset from Kaggle: https://www.kaggle.com/code/rawanma7moud/superstore

# Python Version Used: 3.14.8

# Commands that may need to be ran (py can be used in place of python):
"python -m pip install pandas matplotlib numpy jupyter"
"python -m pip install pandas matplotlib numpy ipykernel"

... or just run the requirements.txt file using this command:
"python -m pip install -r requirements.txt"
